Después de aprender html, se suele aprender css y javascript.

Errores:

-Comenzando desde arriba, se puede observar que hacía falta un “!” para que el código funcionara correctamente.

-Las mayúsculas y el guión entre el 8 en "UTF-8" es por convenio.

-“meta” y “link”, para ser usados no necesitan cerrarse, se cierran ellos mismo. Es más, siempre se escribe solo ya que se autocierra, sin necesidad de “/”

-Todo lo que se escribe tras un “=”, va entre comillas ya que se están declarando valores strings. Estos caracteres deben ir siempre entre comillas.

-No se usan palabras en castellano, oséase, “valor” está mal, se escribe “value”.

-“Hoja de estilos” no tenía un valor real en link, más que causar fallos.

-Debe cerrarse el “head” antes de añadir el “body”, ya que el encabezado y lo que sería el cuerpo de la página web deben estar en orden, no uno dentro del otro.

-Bajo el texto “Corrige…” se pone el cierre de “head” y se abre “body”, ya que se sobreentiende que este es la cabeza de los textos, el enunciado.

-Todo texto, debe tener primeramente un encabezado que explique brevemente de lo que se está hablando, en este caso, “h1” y su correspondiente cierre. En el caso de este proyecto, se usó el “h2” para que no quedara el destacado tan llamativo.

-Cada línea de lo que sería el párrafo, se escribe con “p”, con su correspondiente cierre, no al revés.

-“/body” y “/html” se colocan al final del texto que se haya escrito, para que aparte de que quede escrito de forma correcta, se cierre todo de manera correcta.
